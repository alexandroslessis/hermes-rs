The same Inter t3code's interface uses (it ships the variable build, @fontsource-variable/inter;
these are the static files from its client bundle). Used for the native UI's interface text so
text widths and look match the t3code reference screenshots. The font files are unmodified.
Static files have no Medium (500) or SemiBold (600): those weights draw as Regular and Bold.
